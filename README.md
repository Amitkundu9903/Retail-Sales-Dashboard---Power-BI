# Retail-Sales-Dashboard---Power-BI
An interactive and visually appealing Retail Sales Dashboard built using Power BI to analyze sales performance, profit trends, customer segments, regional distribution, and product insights.

🚀 Features
Dynamic Year-wise Filtering (2019–2024)
Sales, Profit, Quantity & Profit Margin KPIs
Regional and State-wise Sales Analysis
Top Selling Products & Brands
Store Type Performance Insights
Sales vs Last Year Comparison
Interactive and Modern Dark Theme UI
🛠️ Tools & Technologies
Power BI
DAX
Data Modeling
Data Visualization
Business Intelligence
📈 Project Objective

The goal of this project is to transform raw retail data into actionable insights through interactive visualizations and business storytelling.
